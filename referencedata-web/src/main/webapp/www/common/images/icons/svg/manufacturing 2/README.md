# Manufacturing Flat SVG Icons for ON EBX Perspective Menu

Generated as 16x16 SVG vector icons for EBX-style left navigation menus.

Style observations from the provided sample icons:
- Small 16x16 visual footprint.
- Flat, colorful icon language.
- Lightweight shapes with enough contrast for EBX navigation rows.
- Blue/cyan/yellow/green/orange/purple accent palette.

This pack intentionally uses clean vector paths/shapes rather than embedded base64 PNG images, so the icons remain editable, smaller, and easier to theme.

Recommended primary menu highlight for Manufacturing: `material_master.svg`.
